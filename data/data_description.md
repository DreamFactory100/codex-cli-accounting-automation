# ABC Company 가상 회계자료: 2026년 1~3월

모든 기업, 거래처, 거래는 가상이다. KRW 단위의 음수가 아닌 정수 금액을 사용한다. 소규모 상품 판매업체이며 부가세, 원천징수, 기초잔액은 제외한다. 완전한 재무제표 작성 자료는 아니다.

## 구조 및 생성 기준
거래일자, 전표번호, 분개순번, 계정코드, 계정명, 거래처, 차변금액, 대변금액, 적요의 9열이다. 전표번호+분개순번은 유일한 행 키이며 순번은 전표 안에서 1부터 연속된다. 각 행의 차변 또는 대변 한쪽만 양수다. 정상 전표의 대차는 일치한다.
매월 기본 전표 20개 중 처음 2개는 3행, 나머지는 2행이다. 1월과 2월에 전표 복제 1개씩, 3월에 행 복제 1행을 추가하여 총 62전표, 131행이다. 거래일은 2026-01-03~2026-03-23이다. 실습 편의를 위해 월별 기본 금액과 거래 패턴을 반복한다.

## 사전 정의 오류와 정상 사례
- ABC-202601-019: 차변을 1000 증가. 차변-대변 차액 +1000.
- ABC-202602-019: 대변을 2000 감소. 차액 +2000.
- ABC-202603-020: 순번 1을 새 순번 3으로 복제. 차액 +30000. 행 중복과 대차 불일치가 겹치는 하나의 오류 전표다.
- ABC-202601-021, ABC-202602-021: 같은 월의 004 전표 전체를 복제. 대차는 일치하지만 생성 의도상 실제 오류다. 원본 004는 정상이다.
따라서 대차 불일치 전표는 정확히 3개, 실제 오류 전표는 5개, 중복 의심 실제 오류는 3개(전체 복제 2개+행 복제 1개)다. 후보를 자동 오류 확정하지 않는다. 정답표의 실제 오류 표시는 생성 설계에서 알고 있는 사실이다.
- 매월 010 임차료, 011 통신비, 012 급여는 정상적인 월별 반복이다. 날짜가 다르다.
- 매월 017/018은 같은 날, 같은 거래처, 같은 계정과 금액이지만 적요의 주문 A/B가 다른 정상적인 별개 거래다.

## 검증 기준
전표 대차 차액은 차변합계-대변합계다.
행 중복은 같은 전표 안에서 전표번호와 분개순번을 제외한 7개 업무 필드가 같은 경우다. 식별자인 순번은 복제에도 새로 부여하므로 중복 판단에서 제외한다.
전표 전체 중복은 서로 다른 전표에서 식별자 2개를 제외한 7개 필드의 행 다중집합이 일치하는 경우다. 행 순서는 무시하고 각 행의 반복 횟수는 유지한다. 예상 원본/복제 쌍은 2쌍이다.
정상 반복과 정상 동일금액 사례는 이 엄격 기준에서 비후보다. 날짜/거래처/금액만 사용하는 넓은 검색에는 정상 거래가 포함될 수 있으므로 적요와 전표 전체 맥락을 검토해야 한다.

## 정답표 구성과 독립성
기록유형별로 전표검증 62행, 검증사례 17행, 월별계정집계 33행을 제공한다. 실제 오류 사례는 5행, 정상 동일금액 사례는 3행, 정상 월별반복 사례는 9행이다. 분개순번목록은 |로 구분한다. 행 복제 사례의 1|3은 복제 쌍이다. 전표검증 기록은 각 전표의 모든 행 순번을 제공한다. 관련전표/관련순번은 비교 대상이다. 빈 칸은 해당 없음이며 집계 기록에는 전표 식별자가 적용되지 않는다.
정답표는 생성 시 정의한 변경 및 복제 사양과 예상 차액으로 작성했다. 미래 분석 프로그램의 출력은 사용하지 않았다. 월별/계정별 기대 합계는 CSV 직렬화 전에 생성 단계에서 별도로 누적했다. 저장 후 CSV를 다시 읽어 독립적으로 합산해 비교했다.
집계 기준은 거래일자 YYYY-MM와 계정코드이며 차변/대변을 별도로 더한다. 오류와 복제도 포함한 원본 기준이다. 두 CSV는 UTF-8 BOM이며 금액은 쉼표 없는 정수다.
